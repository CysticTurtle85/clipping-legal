Clipper – Privacy Policy

Last updated: 19 October 2026

Clipper is a personal tool that runs only on its owner's own computer and connects only to the owner's own TikTok accounts.

What data Clipper uses

  • TikTok login tokens: used to send drafts to the connected account. They're stored only on the owner's computer.
  • Basic account info and the account's own video statistics (such as view counts): used only to track how the owner's posts perform.

What Clipper doesn't do

  • It doesn't collect data about any other TikTok users.
  • It doesn't sell, share or transfer any data to third parties.
  • It doesn't run any servers. All data stays on the owner's computer.

Deleting data

Disconnecting the app in TikTok's settings, or deleting Clipper's data folder, removes all stored tokens and statistics.

Contact

For questions, contact the owner through the GitHub repository that hosts this page.
